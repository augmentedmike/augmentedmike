## What I'm building

**[AM](https://github.com/augmentedmike/helloam-agentic-kanban)**: an agentic engineering platform. Tasks move through gated states (backlog, in progress, in review, shipped), and a deterministic gate worker checks criteria and tests before anything advances. Each task runs in its own git worktree with per-iteration commits, so every run has an audit trail. Agents plug in through an adapter interface (Claude, OpenAI-compatible, Gemma).
